# app

Личный финансовый PWA-фронтенд: Vite + React + TypeScript (strict) + Redux Toolkit + SCSS-модули.

## Скрипты

- `npm run dev` — запуск дев-сервера
- `npm run build` — типизация (`tsc -b`) и продакшен-сборка
- `npm run preview` — предпросмотр собранного билда
- `npm run lint` — ESLint (строгий type-checked конфиг)
- `npm run typecheck` — проверка типов без эмита
- `npm run test` / `npm run test:watch` — Vitest
- `npm run format` — Prettier для `src`

Алиас `@/` указывает на `src/`.
